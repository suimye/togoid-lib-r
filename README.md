# Figures for the enrichment + UMAP use case (R)

Figures generated by `inst/examples/scRNAseq_enrichment` on **pbmc4k** from the
[TENxPBMCData](https://bioconductor.org/packages/TENxPBMCData/) package
(4,340 cells, 4,336 after QC, 12 Seurat clusters).

Anyone can reproduce them:

```bash
Rscript -e 'BiocManager::install("TENxPBMCData")'
./run_pipeline.sh
```

This branch only holds images, so the feature branch stays free of binaries.
